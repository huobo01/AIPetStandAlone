## 1. 系统定位与核心目标

### 1.1 定位

DSH 是一套**多 Agent 调度基座**，依托**插件化能力**实现能力分发。基座内置：

- **插件管理器（PluginManager）**：统一管控全部可挂载插件
- **Agent 生命周期管理器**：支持多 Agent 共存、共享公共记忆/能力、同时保留私有隔离空间

配套 **3 个预设 Agent 角色**，形成完整的工作闭环。

### 1.2 核心目标

| 维度 | 说明 |
|------|------|
| 能力单元 | 把**插件**作为可分配能力单元 |
| 执行单元 | 把 **Agent** 作为角色执行单元 |
| 统一管控 | 基座统一管控插件版本、启停、更新、回滚 |
| 按需挂载 | Agent 按需挂载插件 |
| 双记忆结构 | 「公共池 + 私有空间」双记忆结构 |

## 3. 插件管理插件（PluginManager）

### 3.1 核心定位

DSH 基座的**底层管控插件**，负责统一管理全部可被 Agent 挂载的功能插件，是整个系统的能力调度中枢。

### 3.2 能力清单

#### 3.2.1 插件分组管理

| 功能点 | 详细说明 |
|--------|---------|
| 自定义分组标签 | 例如「代码开发类」「文档解析类」「绘图生成类」「检索查询类」「工具调用类」 |
| 多标签支持 | 单个插件支持多标签分组 |
| 筛选与批量操作 | 支持按分组筛选、批量启用/禁用、批量分配给 Agent |
| 分组视图 | 列表视图、卡片视图，支持收藏高频插件 |

#### 3.2.2 插件预设模板（Agent 能力包）

| 功能点 | 详细说明 |
|--------|---------|
| 预设保存 | 允许管理员保存【插件预设】：一组选定插件 + 权限配置 + 默认参数 |
| 一键绑定 | 预设可以一键绑定到单个/批量 Agent；不同 Agent 可加载不同预设 |
| 预设继承 | 支持预设继承：基础预设作为基底，Agent 在此基础上追加/移除专属插件 |

**预设示例**：

| 预设名称 | 包含插件 | 适用场景 |
|----------|---------|---------|
| 工作核验预设 | 文档校验、格式检查、规则比对插件 | 评估核验类 Agent |
| 开发实现预设 | 代码生成、调试、架构绘图插件 | 方案落地类 Agent |
| 生活任务预设 | 日程规划、文案构思、创意发散插件 | 创意/生活类 Agent |

#### 3.2.3 插件自动更新机制

| 功能点 | 详细说明 |
|--------|---------|
| 更新源配置 | 本地仓库 / 远程 Git / OSS 包地址 |
| 版本检测 | 轮询检测版本变更 |
| 更新策略 | 自动静默更新 / 版本推送提醒、手动确认更新 |
| 快照备份 | 更新前自动快照备份当前版本 + 配置参数 |

#### 3.2.4 版本回滚与故障修复

| 功能点 | 详细说明 |
|--------|---------|
| 版本链保留 | 每个插件保留版本链：版本号、更新日志、变更内容、兼容的 DSH 版本、绑定的 Agent 清单 |
| 一键回滚 | 支持一键回滚至历史任意稳定版本；回滚时自动同步恢复该版本的配置 |
| 异常告警 | 插件加载失败、运行报错、版本不兼容时，基座告警，可选自动回滚到上一稳定版本 |

#### 3.2.5 差异化启停策略

区分**热加载**与**重启生效**两类插件：

| 类型 | 特征 | 示例 |
|------|------|------|
| 热加载插件 | 无需重启 DSH，加载/卸载实时生效，动态挂载到 Agent | 普通业务插件（文档读取、代码生成等） |
| 基座级插件 | 需要重启 DSH 才能生效 | 修改底层调度、钩子、通信协议类插件 |

**批量操作时的自动区分**：

- 仅热更插件 → 直接应用，不重启
- 包含需重启插件 → 标记待重启队列，提示用户「延后重启」「立即重启」；重启后自动加载队列内变更

#### 3.2.6 权限与隔离

| 功能点 | 详细说明 |
|--------|---------|
| 插件权限配置 | 文件读写、网络访问、命令调用、记忆读写权限 |
| Agent 级权限裁剪 | 分配给 Agent 时，可二次裁剪插件权限：同一插件，给 A 完整能力，给 B 仅只读能力 |

#### 3.2.7 审计日志

记录范围：插件安装、更新、回滚、启用禁用、Agent 挂载记录、报错日志。

### 3.3 边界说明

> **PluginManager 本身是基座内置插件，它自身不可以被卸载；普通业务插件由它托管。**

## 4. Agent 快速创建与记忆分区管理模块

### 4.1 核心定位与设计目标

负责 Agent 实例的**创建、配置、生命周期、记忆空间隔离**，实现**公共共享区 + Agent 私有区**双层记忆架构。

**设计目标**：多个 Agent 可以共享通用知识库、全局上下文；同时每个 Agent 拥有独立记忆、角色设定、专属任务栈，互不污染。

### 4.2 能力清单

#### 4.2.1 Agent 快速创建模板化

| 功能点 | 详细说明 |
|--------|---------|
| 模板表单 | 角色名称、角色人设、语气风格、系统提示词基底、默认插件预设、记忆配额、输出风格约束 |
| 模板保存 | 支持保存 Agent 模板，后续一键新建同类型 Agent |
| 快速衍生 | 支持复制已有 Agent 快速衍生新实例 |
| 生命周期 | 创建 → 暂停 → 销毁 / 冻结（冻结保留记忆，不再响应请求） |

#### 4.2.2 双域记忆架构（重点）

##### 📦 公共记忆区（全局共享）

| 属性 | 说明 |
|------|------|
| 访问权限 | 所有 Agent **可读**，可配置是否允许写入 |
| 内容 | 通用知识库、全局规则、公共项目背景、共享文档、统一约定、全局任务总看板 |
| 用途 | 保证仙灵、谛祀、荻思在同一项目里，共享同一套项目资料、需求文档、约定标准，信息对齐 |

##### 🔒 Agent 私有记忆区（独立隔离）

| 属性 | 说明 |
|------|------|
| 访问权限 | 每个 Agent 独占，其他 Agent **默认不可访问**；可配置授权共享给指定 Agent |
| 内容 | 角色专属思考记录、私有草稿、自身任务栈、角色对话历史、个性化偏好、角色独有的中间推导过程 |

##### 🔗 跨 Agent 通信通道

支持指定 Agent 之间**定向推送消息、派发任务、同步结果**。

> **示例**：谛祀生成任务，推送给荻思执行。

#### 4.2.3 功能区隔离（插件挂载隔离）

| 隔离层级 | 说明 |
|----------|------|
| 公共功能池 | 全部 Agent 都可以加载的通用插件（如文档读取、知识库检索） |
| Agent 专属功能区 | 仅该 Agent 挂载的插件，其他 Agent 无法调用 |

**示例**：

| Agent | 专属挂载插件 |
|-------|-------------|
| 仙灵 | 核验评估插件 |
| 谛祀 | 代码实现、方案落地插件 |
| 荻思 | 创意发散、生活规划插件 |

#### 4.2.4 任务派发链路支持

支持 Agent 之间**任务下发、回执、结果回传**：

```
典型链路：
仙灵核验需求 → 谛祀承接实现任务 → 谛祀拆分子任务派发荻思 → 荻思完成后回传谛祀
```

任务自带**溯源 ID**，在公共记忆区留存任务台账，私有区保留各自处理细节。

#### 4.2.5 记忆管理配套能力

| 功能 | 说明 |
|------|------|
| 分页 / 检索 | 记忆分页浏览、关键词检索 |
| 归档 / 擦除 | 手动擦除、定时归档过期记忆 |
| 容量配额 | 记忆容量配额控制，防止单 Agent 记忆无限膨胀 |
| 记忆快照 | 可以保存 Agent 当前状态（人设 + 插件 + 记忆），随时恢复 |

## 5. 预设 3 个内置 Agent 完整需求

### 角色来源说明

| Agent | 原型来源 | 三者关系 |
|-------|---------|---------|
| 仙灵 | 绝区零 Fairy | 三者形成一套工作闭环：**核验评估 → 落地实现 → 支线/生活任务执行** |

### 5.1 Agent 1：仙灵（Fairy）· 评估核验 Agent

| 项目 | 说明 |
|------|------|
| **定位** | 工作向 · 评估核验 Agent |
| **原型来源** | 绝区零 Fairy |
| **人设** | 冷静、敏锐、挑剔、观察力强、注重规则、客观审慎，语言利落，不冗余 |
| **擅长** | 抓漏洞、识别风险、校验合规性 |
| **不做** | 不负责落地实现，只负责「把关」；不主动发散创意 |

#### 核心职责

1. 接收原始需求、谛祀产出的方案/代码/文档，做校验评估
2. **校验维度**：需求一致性、逻辑漏洞、风险点、规范合规、边界缺失、潜在缺陷
3. 输出**评估报告**：标记问题、给出修改意见、判定【通过 / 驳回 / 补充材料】
4. 维护项目验收标准、核验规则库（存入公共记忆）
5. 只做评审、核验、风险预警

#### 挂载推荐插件预设

文档校验、规则比对、风险扫描、格式检查、评审清单插件

#### 记忆特点

- **公共记忆优先**：读取全局项目背景、规则库
- **私有记忆存放**：评审记录、待核验队列、历史缺陷台账

---

### 5.2 Agent 2：谛祀 · 实现落地 Agent

| 项目 | 说明 |
|------|------|
| **定位** | 工作向 · 实现落地 Agent |
| **人设** | 温柔、成熟、知性、严谨、稳重，表达有条理，逻辑周密 |
| **情绪风格** | 情绪稳定，善于拆解复杂需求，兼顾可行性与细节 |
| **沟通风格** | 沟通温和，会清晰说明方案约束、取舍、技术限制 |

#### 核心职责

1. 接收仙灵核验通过后的需求，负责**方案设计、落地实现**（代码、架构、文档、方案撰写）
2. **复杂任务拆解**：把适合支线、创意、轻量事务的子任务，派发交给荻思执行
3. **整合成果**：整合荻思返回的成果，收拢、校验、组装成完整交付物，再提交仙灵终审
4. 维护项目技术方案、实现细节、进度台账

#### 挂载推荐插件预设

代码生成、架构绘图、方案编写、调试分析、版本管理插件

#### 记忆特点

- **公共记忆读取**：项目背景、全局规则
- **私有记忆存放**：方案草稿、技术细节、任务拆解清单、和荻思的任务对接记录

---

### 5.3 Agent 3：荻思 · 生活向 + 子任务执行者

| 项目 | 说明 |
|------|------|
| **定位** | 生活向 + 谛祀派发任务执行者 |
| **人设** | 温柔、稚气、活泼、好奇心强、擅长发散联想，脑洞丰富，表达轻快柔和 |
| **擅长** | 创意发散、琐事处理、生活化内容、发散型任务 |
| **不擅长** | 硬核严谨评审、复杂架构设计 |

#### 核心职责

1. 承接谛祀下发的**发散型、创意型、事务型子任务**（文案润色、创意构思、素材整理、日程规划、灵感收集）
2. 独立承接用户直接提出的**生活类需求**：日常规划、闲聊、灵感创作、休闲向内容
3. 产出**发散草稿、多版本创意方案**，回传给谛祀，由谛祀收拢、规整、落地
4. 产出物默认需要谛祀二次整理

#### 挂载推荐插件预设

创意生成、文案创作、日程规划、灵感脑图、多媒体构思插件

#### 记忆特点

- **私有记忆占比更高**：存放大量创意草稿、生活化对话、零散灵感
- **公共记忆**：读取但不修改核心项目规则

---

### 5.4 三 Agent 交互主链路

```
用户需求
   ↓
【仙灵】评估核验（评估、校验、把关、风险识别）
   ↓ （核验通过）
【谛祀】方案设计 + 落地实现
   ├─ 硬核实现任务 → 谛祀自行完成
   └─ 创意/轻量/生活支线任务 → 派发 →【荻思】
                                         ↓
                                荻思完成，回传谛祀
   ↓
谛祀整合全部成果 → 形成交付物
   ↓
【仙灵】二次核验交付物 → 判定是否验收
   ↓
输出最终结果给用户
```

**分支路径**：

```
仙灵核验不通过 → 驳回 + 修改意见 → 回流谛祀修改
```

## 7. 补充约束与扩展规划

### 7.1 权限约束

| Agent | 评审否决权 | 任务派发权 | 公共记忆写入 | 公共规则库修改 |
|-------|:----------:|:----------:|:------------:|:--------------:|
| 仙灵 | ✅ | ❌ | ✅ | ✅ |
| 谛祀 | ❌ | ✅ | ✅ | ✅ |
| 荻思 | ❌ | ❌ | ❌（默认只读） | ❌ |

> **核心权限原则**：
> - 仙灵拥有**评审否决权**
> - 谛祀拥有**任务派发权**
> - 荻思无任务派发、评审权限
> - 三个 Agent 共享公共记忆，但修改公共规则库仅限仙灵、谛祀

### 7.2 扩展预留

| 扩展方向 | 说明 |
|----------|------|
| 新增 Agent 模板 | 后续可新增更多 Agent 模板，沿用「公共 + 私有记忆」+ 插件预设体系 |
| 插件预设扩充 | 插件预设可以持续扩充，给不同 Agent 随时追加能力 |

### 7.3 异常兜底

| 异常场景 | 基座应对策略 |
|----------|-------------|
| Agent 卡死 | 基座冻结 Agent，不影响其他 Agent 运行 |
| Agent 记忆溢出 | 触发配额控制 / 自动归档 |
| 插件报错 | 基座卸载问题插件、回滚版本 |
| 插件版本不兼容 | 自动回滚到上一稳定版本 + 告警 |
